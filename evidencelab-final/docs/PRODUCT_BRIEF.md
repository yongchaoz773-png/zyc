# EvidenceLab 产品说明

## 用户痛点与画像

投资命题常把事实、解释和结论混在一句话里。研究员需要在不同财报、公告与数据接口间反复核对，又容易忽略反向证据、统计口径和结论失效条件。目标用户是投研助理、买方/卖方研究员及需要形成可复核研究记录的个人研究者。

## 目标与非目标

目标是把模糊命题转成可证伪问题，组织支持/反对/无法验证证据，保留冲突与缺口，形成可追溯、可更新的研究任务。非目标包括荐股、收益预测、自动交易、替代审计、用 AI 猜测缺失财务数值或在无后台服务时宣称实时监控。

## 核心流程

`输入命题 → 主体/期间/口径澄清 → 3–6 个子问题 → 证据检索与计算 → 三向分类 → 冲突处理 → 结构化结论 → 变化条件 → 追问/比较 → 保存与导出`

## 功能清单

- 命题提交、澄清、修订、重复提交保护和重新拆解。
- 子问题增删改、判定标准、证据状态、重要性和版本审计。
- 证据方向、类型和来源筛选；原始材料跳转；计算公式展开。
- 来源权威性、期间、单位、口径、后续更正和因果边界冲突规则。
- 当前结论、适用范围、关键反证、无法验证项和待补数据。
- 可编辑的结论变化条件，明确标注“用户设定研究规则”。
- 跨期比较、证据限定追问、任务保存/恢复/完成/重新验证。
- Markdown / JSON 导出和 localStorage v2 损坏隔离。
- 401/403/429/500/503/空数据/错误 Schema 异常演练。

## 关键页面

工作台在一个连续页面内呈现五步：命题输入、当前结论、验证计划、证据链、结论变化条件。右侧保留来源与追问，任务/冲突/比较/编辑采用模态工作区，减少跨页迷失。移动端变为单列。

## 成功指标

- 100% 的确定性结论至少引用一个证据 ID 与来源。
- 100% 的无法验证项给出具体原因和待补信息。
- 接口失败不产生反对证据。
- 关键金融计算边界测试全部通过。
- 用户可在 90 秒内完成“输入—看冲突—追问—保存/导出”演示。

## MVP 与迭代

MVP 使用宁德时代公开报告快照和规则引擎，优先证明产品闭环。下一阶段依次接入授权数据适配器、PDF 页码/片段与哈希、跨公司标准化、云端任务库、模型检索规划与强制引用校验，最后再增加经合规审查的定时复核与通知。
