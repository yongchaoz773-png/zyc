# 90 秒中文演示脚本

| 时间 | 画面与操作 | 旁白 |
|---|---|---|
| 0–10 秒 | 打开工作台，指向“非实时数据快照”和数据源状态 | “EvidenceLab 不是荐股聊天机器人，而是把投资命题变成可核验、可追溯的研究任务。当前演示使用公开财报历史快照。” |
| 10–22 秒 | 保留默认命题，点击“验证命题” | “系统先识别公司、报告期和盈利归因口径，再拆成主营收入与毛利、扣非利润、投资收益和量价成本桥接四个子问题。” |
| 22–36 秒 | 展示结论、三类证据标签，切到反对/无法验证 | “结论不是简单数证据。扣非利润和主营毛利支持经营改善，但投资收益与非经常性损益构成反向证据；缺少量价成本桥接则明确保留为无法验证。” |
| 36–48 秒 | 点击“冲突记录”，展开公式和来源 | “冲突记录说明双方分别能证明什么，并按一手财报、口径与因果边界裁决。每条关键数值都能展开公式并回到巨潮资讯原始报告。” |
| 48–60 秒 | 点击“继续比较” | “跨期比较统一单位和期间。2026 上半年现金流增速明显低于利润增速，系统把它作为盈利质量风险信号，而不是直接判定利润失真。” |
| 60–70 秒 | 点击一个推荐追问 | “追问只在当前证据范围内回答，并引用 O1、O2、S2、S3；超出覆盖范围会明确说证据不足。” |
| 70–80 秒 | 打开变化条件并编辑一个阈值 | “反转条件是可编辑的研究假设，明确标注用户设定；当前通过手动重新验证复核，不宣称后台实时监控。” |
| 80–90 秒 | 点击“保存为研究任务”，打开左侧“研究任务”，关闭后点页脚“异常演练”并选择 503，最后点击顶部 JSON | “任务可以保存、恢复、完成、重验和导出。接口失败时保留已有证据并归为无法验证，不会误当反证。” |

录制前运行 `npm run verify`，再 `npm run dev`。打开 `http://localhost:4173` 后先刷新一次，确认顶部显示“非实时数据快照”、左侧任务数为 0 或已知值。建议 1440×900、浏览器缩放 90%，关闭无关标签页。视频尚未录制，需要按本脚本人工录屏并上传；localhost 只用于录制，不得作为公开 Web URL 提交。
